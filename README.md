# PP3 Product Settings – North Sails Sri Lanka

Operator web app for Pre Preg Line 3: record each product run (run date, line speed, notes) with photos of the HMI screens, so settings can be restored later.

- Live app: https://kitesurfingant-ops.github.io/pp3-settings/
- Data: Supabase project `ant-data` (tables `ns_products`, `ns_photos`, view `ns_product_list`)
- Single file: `index.html` – no build step.
